This is a simple 3D engine based on the OpenGL API, that can load .obj-files via a home made importer.
You can explore the 3D models using typical freelook FPS-style mouse and keyboard support.
There are some extra options in the fragment shader to allow for a cool concentric ring effect (time has to be made a uniform variable in that case).

The GLEW library is used for OpenGL support, and SDL2 for window management.
